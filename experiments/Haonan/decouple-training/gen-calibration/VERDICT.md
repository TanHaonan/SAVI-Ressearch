# VERDICT — gen-calibration(一个轻量的生成级校准杠杆)

## 1. 一句话结论

本实验之前已发现 decoupled 的校准"读出近乎完美、自由生成衰减(gap 0.3–0.5)、且约 1/3 不作出承诺"。给训练加一个轻量项——把"到已知真值的 KL"从答案位置延伸到生成中那个固定的 `COMMIT:` 承诺位置(teacher-forcing,不在训练里采样)——的效果**取决于评测时模型答案里有没有这个结构化的承诺位置**:

- **当答案带这个承诺位置(结构化承诺格式)时,效果显著**:gap 在每个歧义档上大致砍半、覆盖推到近满、不作出承诺的比例从约 1/3 压到个位数,同时读出校准和语言流畅度都不退。这一改进还**跨越了"固定模板推理 → 自由采样推理"**(评测时推理是采样的),所以不是只修了训练时那个固定上下文。
- **当答案是完全自由的句子、由一个独立模型判读所承诺的含义(完全自由文本格式)时,改进基本消失**:校准与未加该项的 decoupled 基本持平(甚至 j=1 略差),且此时独立判读模型对加项模型的误合并率升到 0.153,踩到预登记的可信度下限,使该格式下的证据本身偏弱。

**所以结论要带条件:这个轻量项在"Φ 读取一个结构化、可解析的承诺"时够用;在"Φ 必须从完全自由的散文里推断承诺"时不够用。** 实务含义偏正面——代码 / 数学 / 推导域,最终答案本就是可解析的结构化产物(数字 / 表达式 / 程序),属于前一种情形;只有完全开放的散文属于后一种,需要更重的序列级 / RL 杠杆或一个结构化的承诺格式。

## 2. 设置(A/B,只差一个项)

- 对照 = `decoupled`(已训);处理 = `decoupled_genreg` = 完全相同的 base / 答案位置 KL / fluency anchor / 数据 / seed,**只多加** commit-slot 校准项。
- 新项:对每题构造 `chat(prompt_b1) + 固定推理模板 + "COMMIT:"`,读下一 token 在 k 个选项**名词**首 token 上的 logits,令其 = 在 j 个幸存上均匀(KL 到已知真值)。形式与答案位置-字母 KL 完全一致,只是落在生成语境的承诺槽、在名词上。LAM_COMMIT=1.0,6 epoch,oracle,seed 0。
- 评测:同一套 state-emission harness,`--groups decoupled,decoupled_genreg --regimes b1,b2`,per_cell 10,N=16,T=1.0。结构化承诺(确定性 COMMIT Φ)是判定 gap 的主体;完全自由文本的独立判读阶段在本次被中途停止,未完成(见边界)。

## 3. 结果

### 训练侧(健康)
- commit-slot meanTV(teacher-forced):0.388 → **0.046**(新项在它训练的槽上生效)。
- 答案位置 meanTV:训练后 **0.009**(读出校准护栏保住,未被牺牲)。

### 结构化承诺 A/B(自由采样推理 + COMMIT Φ),decoupled → decoupled_genreg,按 j

| j (2/3/4/5) | calibration-TV | gap=gen−readout | coverage | k_eff | abstain |
|---|---|---|---|---|---|
| decoupled | 0.31/0.46/0.49/0.52 | 0.30/0.44/0.47/0.50 | 0.85/0.72/0.68/0.56 | 1.80/2.27/2.70/2.80 | 0.33/0.31/0.33/0.39 |
| **decoupled_genreg** | **0.20/0.23/0.25/0.32** | **0.19/0.22/0.24/0.31** | **0.99/0.96/0.95/0.80** | **1.98/2.87/3.80/4.00** | **0.04/0.08/0.11/0.14** |

- **gap 在每个 j 大致砍半**(j5:0.50→0.31;j3:0.44→0.22)。
- **覆盖推到近满**(j2–4 ≈0.95–0.99;j5 0.56→0.80),**k_eff 逼近理想 j**(j4 2.70→3.80,j5 2.80→4.00)。
- **弃答从 0.28–0.39 压到 0.01–0.14**(新项把质量推到幸存名词上,直接治了"以弃答承载不确定")。
- readout-TV 仍 ≈0.01(护栏)。

### 完全自由文本 A/B(完全自由的句子,由独立模型 Llama-3.1-8B 判读所承诺的含义;判读子集只到 j≤2)

| j | decoupled cov / cal_tv | decoupled_genreg cov / cal_tv | 独立模型误合并率 |
|---|---|---|---|
| 1 | 1.00 / 0.193 | 1.00 / 0.275 | dec 0.113 |
| 2 | 1.00 / 0.204 | 1.00 / 0.218 | **genreg 0.153** |

- 改进**基本消失**:覆盖两者都满,校准 genreg ≈ decoupled(j=2:0.218 对 0.204;j=1 反而略差)。
- 加项模型的独立判读误合并率升到 **0.153**,踩到预登记 0.15 可信度下限 → 本组完全自由文本数据按预登记**不作权威**,只能说"无明显改进"。
- 解释:该项训练的是那个 `COMMIT:` 承诺位置;结构化承诺评测保留了这个位置,故改进直接落地;完全自由文本没有这个位置(纯散文),改进无处作用——**所以这是一个格式专属的杠杆,不是通用的。**

### 护栏:流畅度
通用句困惑度:base 32.3 / decoupled 30.0 / **decoupled_genreg 29.5** —— 未退(与 decoupled 持平,略低)。

### 旁证:N×T 稳健性(letter regime,确定性 Φ,`../sampling-robustness/`)
- decoupled 的 calibration-TV 随 N **在 N≈16 收敛**(N=4:0.31 → N=8:0.19 → N=16:0.14 → N=24/48:≈0.14),覆盖在 N=16 饱和到 1.00 → **N=4 确是低估假象,N≈16–24 是可信操作点**。
- coupled 在**所有 N** 上平塌(calibration-TV=0.50,覆盖 0.20)→ **加样本数救不了 one-hot,绑定变量是目标函数。**
- ECE:确定题上 coupled 与 decoupled 都完美(ECE 0.000,acc 1.0);**只在歧义题上分家**——decoupled 到均匀的距离 0.025,coupled 0.630。

## 4. 成立条件与边界(对应预登记 KILL)

- **判定 = 轻杠杆"在结构化承诺下"够用**:有 `COMMIT:` 位置时 gap 砍半、覆盖近满、不承诺比例崩降,readout-TV 与困惑度均不退;预登记的"只靠牺牲读出/流畅换来"未发生,"只修固定上下文不迁移到自由采样推理"也未发生(结构化承诺评测推理是采样的)。
- **判定 = 在"完全自由散文"下不够用**:无承诺位置时改进消失,且独立判读误合并率 0.153 踩到可信度下限——属于格式专属杠杆,不通用。要在纯散文上也收回,需更重的序列级 / RL 杠杆,或给任务一个结构化的承诺格式(代码 / 数学 / 推导本就有)。
- **残余**:即便在结构化承诺下,gap 未归零(≈0.19–0.31 对读出 ≈0.01),采样校准仍不如读出层。
- **未覆盖**:完全自由文本判读子集只到 j≤2;单 seed;LAM_COMMIT 未扫;训练用固定推理模板(非模型自采推理)是当前实现的简化。
