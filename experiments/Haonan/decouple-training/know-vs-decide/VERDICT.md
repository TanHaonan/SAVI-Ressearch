# VERDICT — 在冲突语境消歧上，正确答案已在前向中、但被过早的承诺盖住；从中间层读出并晚一步作答即可恢复

## 一句话结论

把"对各候选义的信念（belief）"与"承诺到某一个答案（commit）"拆成两步：从冻结模型的中间层读出它对词义的偏好、晚一步再回答，作答准确率从模型原生前向的 0.527 升到 0.952（gap +0.42，bootstrap CI[0.34, 0.51]）；控制承诺温度（temperature）的旋钮改变 calibration（ECE 从 0.027 走到 0.352）而几乎不动判别准确率（accuracy 恒定约 0.911）；只用排序（ranking）训练判别头得到 0.914，与用 cross-entropy（CE）训练得到的 0.949 接近。

## 设置

- **Model：** frozen Qwen3-4B，eval-only。本实验不训练 backbone、不更新 LoRA；只在冻结模型的中间层隐状态上训一个很小的线性打分头（per-candidate 共享权重，对两个义各算一个标量分），并在答案位置做一次读出与晚承诺。
- **Carrier：** bank/ATM 式的语境消歧。每条给一个一词多义的词（如 bank / cloud），一段语境（scene）已经把词义唯一确定，但局部词共现会把模型往错义带（例如语境讲的是天空里的云，句中却出现 "buffering / backup / upload" 这类把模型拉向"云服务器"义的词）。每条配一个 yes/no 问题与 gold。平衡的 matched-pair 评测切片 n=146（cued 义 a/b 各 73、gold yes/no 各 73），按词留出约 1/3（leave-words-out）作为泛化测试。另有 18 条人工编写的题，仅用于 face validity，不进主指标。
- **Metric：**
  - 词义判别：在留出词上读出的义与 cued 义是否一致（accuracy），以及打分差的 AUC。
  - 作答：先用读出的义判 yes/no（yes iff 读出的义 == 问题问的义），与模型原生前向的 yes/no（greedy 承诺）比 accuracy。
  - 承诺校准：yes/no 概率的 expected calibration error（ECE）。
- **对照组：**
  - 原生前向（greedy 承诺）作为下界。
  - 训练判别头时，纯排序损失（margin hinge，只压"cued 义分 > 另一义分"、不压幅值）对比 cross-entropy（会同时把概率推尖）。
  - 承诺时扫一组 temperature T（0.25 到 8），看判别与校准是否独立移动。

## 结果

数值见 `results.json`。

**1. 晚承诺恢复了原生前向丢掉的答案。** 在 n=146 的留出切片上：

| 作答方式 | accuracy |
|---|---|
| 模型原生前向（greedy 承诺） | 0.527 |
| 读出义 + 晚承诺 | 0.952 |

gap +0.42，配对 bootstrap 95% CI[0.34, 0.51]，下界排除 0。读出的义本身准确率也是 0.952。也就是说，正确答案在模型这一遍前向里本就可读出，是过早、过尖的 greedy 承诺把它盖住。

**2. 承诺旋钮与判别基本独立。** 在排序训练得到的判别头上扫 temperature T：作答 accuracy 恒定在约 0.911（range 0.000），而 ECE 从 0.027（T=0.5）单调走到 0.352（T=8），平均置信度与熵随之平滑变化。也就是说，"承诺多确信"这个旋钮可以单独调，不牵动"判别对不对"，并且存在一个可单独挑出的低 ECE 工作点（T=0.5，ECE 0.027）。

注：accuracy/AUC 对单调的 temperature 不变是构造上的必然（temperature 不改变 argmax 与排序），这正是解耦设计要的性质；非平凡的部分是 ECE 确实有大跨度（0.027→0.352），说明 calibration 这个自由度真实存在且可独立移动。

**3. 判别基本不依赖把概率推尖。** 纯排序损失训出的判别 accuracy 0.914（AUC 0.965），cross-entropy 训出的 0.949（AUC 0.980），二者接近。也就是说，把正确义排到前面这件事，大体不需要"把概率压到单峰"的尖度压力。

## 成立条件与边界

- 上述恢复（0.527→0.952）出现的条件是：词义由语境唯一确定、但局部高先验把 greedy 承诺拉错——即一类"答案已在前向、只是没被用上"的情形。在这类 carrier 上，问题不是模型不知道，而是承诺太早；读出 + 晚承诺即可恢复。条件之外（语境本身不能确定义、或义难以从中间层线性切分）不保证成立。
- "排序≈CE"是近似而非相等：accuracy 差 0.914 vs 0.949（差 0.035），AUC 差 0.965 vs 0.980。结论是判别"大体"不需要尖度压力，留有小残差；margin hinge 可能略欠拟，换软成对代理或可补平（未试）。不宣称"判别完全不需要尖度"。
- temperature 与判别独立中，"accuracy/AUC 对 T 不变"是 monotone temperature 的构造保证；可报告的内容是 ECE 的可移动区间与可挑出的低 ECE 工作点，而非"发现了判别与校准无关"这一更强主张。
- 全程冻结 backbone 与读出/承诺层，只动一个小线性头；结论限定在 state / readout 层。这里"该不该确信"的形状停在答案位置的读出上，本实验未检验它是否进入自由生成。
- 单一 carrier（Qwen3-4B、bank/ATM 词义）、只有 16 个基础词、词义易做线性切分；不保证迁移到更难的推理或更一般的任务。
